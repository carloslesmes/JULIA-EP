Variable aleatoria discreta v.a.

Una variable aleatoria \(X\) es una función del espacio muestral en los números reales. \[ \begin{align*} X: & \Omega \to \mathbb{R} \\ & \omega \mapsto X(\omega) \end{align*} \]

Función de densidad de probabilidad f.d.p.

Una función \(f\) de los reales en el intervalo \([0,1]\) \[ \begin{align*} f : & \mathbb{R} \to [0,1] \\ & x \mapsto f(x) \end{align*} \] dada por \[ f(x)=P(X=x)=P( x \in \Omega \vert X(\omega)=x) \]

es una función de densidad de probabilidad para una variable aleatoria \(X\).

Propiedades

  1. \(f(x) \ge 0 \quad\forall x \in \mathbb{R}\)

  2. \(\displaystyle\sum_{x \in \mathbb{R}} f(x)=1\)

Media de una variable aleatoria

\[ E(X)=\mu_X=\sum_{x \in \mathbb{R}}xf(x)\]

Varianza de una variable aleatoria

\[V(X)=\sigma^2_X=\sum_{x \in \mathbb{R}}x^2f(x)-\mu_X^2\]

Desviación estándar de una variable aleatoria

\[\sigma_X=\sqrt{V(X)}\]

Función de distribución acumulada F.d.a.

\[F(x)=P(X\leq x)=\sum_{t\leq x}f(t)\]

Propiedades

  1. \(\displaystyle\lim_{x \to -\infty}F(x)=0\)
  2. \(\displaystyle\lim_{x \to \infty}F(x)=1\)
  3. F es creciente
  4. \(P(a < X \le b)=F(b)-F(a)\)

Propiedades

Sea k una constante y X una va, se tiene:

  1. \(E(X+k)=E(X)+k\)
  2. \(E(kX)=kE(X)\)
  3. \(V(X)=E(X^2)-E(X)^2\)
  4. \(V(X+k)=V(X)\)
  5. \(V(kX)=k^2 V(X)\)

Variables aleatorias continuas

Una función \(f_{X}(x)\) es una función de densidad de probabilidad para una variable aleatoria continua si y sólo si:

  1. \(f_{X}(x) \ge 0, \forall x \in \mathbb{R}\)
  2. \(\int_{-\infty}^{\infty}f_{X}(x)\, dx=1\)

Media de una variable aleatoria continua

\[ E(X)=\mu_X=\int_{-\infty}^{\infty} xf_{X}(x)\,dx\]

varianza de una variable aleatoria continua

\[ V(X)=\sigma_{X}^{2}=\int_{-\infty}^{\infty} x^{2}f_{X}(x)\,dx-\mu_{X}^{2} \]

Desviación estándar de una variable aleatoria contunua

\[ \sigma_X=\sqrt{V(X)}\]

En general \[ E(g(X))=\int_{-\infty}^{\infty}g(x)f(x)\,dx \]

Función de distribución acumulada F.d.a.

\[F(x)=P(X\leq x)=\int_{-\infty}^x f(t)\, dt\]

Propiedades

  1. \(\displaystyle\lim_{x \to -\infty}F(x)=0\)
  2. \(\displaystyle\lim_{x \to \infty}F(x)=1\)
  3. F es creciente
  4. \(P(a < X < b)=F(b)-F(a)\)
  5. \(\displaystyle\frac{d F(x)}{dx}=f(x)\)

\(P(X=a)=0, P(X< a)=P(X \le a)\)

Ejemplo

Sea \[ f(x)= \begin{cases} 2x & \text{si} \quad 0 \leq x \leq 1 \\ 0 & \text{otro caso} \end{cases} \]

Para que una función f(x) sea una f.d.p. se debe comprobar que:

  1. \(f(x) \ge 0\)

  2. \(\int_{-\infty}^{\infty}f(x)\,dx=\int_{0}^{1}2x\,dx=x^2\big|_{0}^{1}=1\)

es una f.d.p.

$ E(X)=_0^1 2x^2 , dx=x3|_{0}{1}=$

\(V(X)= \int_0^1 2x^3 \, dx-\big(\frac{2}{3}\big)^2=\frac{x^4}{2}\big|_0^1-\frac{4}{9}=\frac{1}{2}-\frac{4}{9}=\frac{1}{18}=0.0\bar{5}\)

\(\sigma_X=\sqrt{\frac{1}{18}}=0.2357...\)

\[ F(x)= \begin{cases} 0 & \text{si}\quad x < 0 \\ \int_0^x 2t\,dt=x^2 & \text{si} \quad 0 \leq x \leq 1 \\ 1 & \text{si}\quad x \ge 1 \end{cases} \]

Distribución triangular

\[ f(x)= \begin{cases} x & \text{si} \quad 0 \leq x \leq 1 \\ 2-x & \text{si} \quad 1 \leq x \leq 2 \\ 0 & \text{otro caso} \end{cases} \]

  1. \(f(x) \ge 0 \quad \forall x \in \mathbb{R}\)
  2. \(\int_0^1 x \,dx + \int_1^2 2-x \,dx=\frac{x^2}{2}\big|_0^1 + (2x-\frac{x^2}{2})\big|_1^2=1\)

\(E(X)=\int_0^1 x^2 \, dx + \int_1^2 2x-x^2\,dx= \frac{x^3}{3}\big|_0^1 + (x^2-\frac{x^3}{3})\big|_1^2=1\)

\(V(X)=\int_0^1 x^3 \, dx + \int_1^2 2x^2-x^3 \, dx - 1= \frac{x^4}{4}\big|_0^1+ (\frac{2x^3}{3}-\frac{x^4}{4})\big|_1^2-1= \frac{1}{6}\)

\(\sigma_X=\sqrt{\frac{1}{6}}=0.408248...\)

\[ F(x)= \begin{cases} 0 & \text{si} \quad x < 0 \\ \int_0^xt\, dt=\frac{x^2}{2} & \text{si} \quad 0 \leq x < 1 \\ \frac{1}{2}+\int_1^x 2-t \, dt=-\frac{x^2}{2}+2x-1 & \text{si} \quad 1 \leq x < 2 \\ 1 & \text{si} \quad x \ge 2 \end{cases} \]
